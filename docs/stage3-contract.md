# Stage 3 contract — recorded before implementation

Approved 2026-10-21: retain one allocated slot and separate 1R1W banks. Every command makes both nonempty requests eligible on the following edge; each request independently holds valid/payload until accepted. A requests (base,S); B requests (base+S,N-S). Empty segments have no request or response ownership. Allow consumption before either full-block completion or acceptance of the other interface's request.

Per-interface request-sent flags prevent repeats; per-bank committed counts advance only on the corresponding response handshake. Prefix/suffix writes can occur at the same edge. A pre-edge validity check authorizes only the next logical word. Retain the baseline's one-cycle synchronous read, elastic output, separate read/consume counters and final-consumption slot release. Shared reset cancels both interfaces and all partial/held state without clearing bank data. The single-memory controller and its checker remain unchanged.

Required directed checks: independent and simultaneous request acceptance; A-first/B-first response order; simultaneous writes; B finished before A starts; A consumption before B accepts; consumer stalls including bank transition and final word; repeated blocks; reset with asymmetric request ownership, partial writes or held output; supported N/S boundaries; invalid parameters and last-marker checks. Reproduce both approved eight-word arrival/consumption tables after normalizing the request edge. Use the existing command-address scoreboard without adding split or response inputs. Include explicit witnesses so a test cannot pass without exercising its named condition. No double buffering, performance sweep, random campaign or device synthesis in this stage.
